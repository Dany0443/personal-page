What I do

I spend most of my free time managing my home servers, automating Linux systems, and running services I actually use every day. Here is what my current self-hosted stack looks like.

Privacy & Search

AdGuard Home

Network-wide DNS server for ad blocking, tracker prevention, and local domain rewrites across all home devices.

SearXNG

Privacy-respecting metasearch engine that aggregates results from multiple engines without tracking or profiling search queries.

Media & Photos

Immich

Self-hosted photo and video management solution with automatic phone backups, facial recognition, and albums.

Navidrome

Lightweight music server and streamer for listening to my personal FLAC and MP3 music collection from any client.

Infrastructure & Monitoring

Beszel

Minimalist, resource-friendly server monitoring hub and agent for tracking CPU, memory, disk, and docker container stats.

Pterodactyl

Open-source game server management panel and Wings daemon running servers in isolated Docker environments.

Game Servers

CS2 Dedicated Server

Private Counter-Strike 2 dedicated server instance configured for matches, practice, and custom workshop maps.

Minecraft Server

Fabric server instance running a survival world with friends, performance optimization mods, and automated backups.
